Phone-first study labs, hosted with GitHub Pages.

| Lab | Path |
| --- | --- |
| Science Lab · 6th grade Scientific Method | [`science/`](science/) |

Each lab is a single self-contained `index.html`. Progress is saved in the browser on that device.
To use one full screen on an iPhone, open it in Safari, tap **Share**, then **Add to Home Screen**.
